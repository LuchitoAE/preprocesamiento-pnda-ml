# Preprocesamiento de 5 datasets de la PNDA

Trabajo del curso de Machine Learning. Cada notebook descarga un dataset
de la Plataforma Nacional de Datos Abiertos del Peru y aplica su preprocesamiento.

| # | Notebook | Dataset |
|---|----------|---------|
| 1 | `01_etes.ipynb` | Gasto Presupuestal ETES 2024 (MEF) |
| 2 | `02_fallecidos_covid.ipynb` | Fallecidos por COVID-19 (MINSA) |
| 3 | `03_endes.ipynb` | ENDES 2024 - REC42 (INEI) |
| 4 | `04_enaho.ipynb` | ENAHO 2024 - Modulo 01 (INEI) |
| 5 | `05_nna_cedif.ipynb` | NNA atendidos en CEDIF (INABIF) |

Cada notebook se abre y se corre por separado, son independientes entre si.
